# Zambaara

Four elemental hourglasses (Ignis, Pluvia, Ventus, Mons) as an installable web app.
Plain static files, no build step.

## Live links
- GitHub Pages: https://harshmohan14.github.io/Zambara/ (served from the `gh-pages` branch)
- Vercel: import this repo as a new Vercel project, set the production branch to `gh-pages`. `vercel.json` tells Vercel to serve the folder as-is.

## Install on a phone
- Android (Chrome): open the link, then menu → Install app.
- iPhone (Safari): Share → Add to Home Screen. Tap "Use motion" once to allow the gyroscope.

## Android APK
Go to pwabuilder.com, paste the live link, choose Android, and download the package.

## How it behaves
- Tilt to pour; turn the phone upside down to flip the glass.
- Switching element keeps the running timer, and the timer survives closing the app.
- Progress (essence, mastery, seals) is stored on the device.
